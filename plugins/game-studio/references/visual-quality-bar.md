# Visual Quality Bar

Game Studio visual work follows an explicit quality loop.

## Minimum standard
- Reference-driven rather than generic.
- Authored assets when the target calls for them.
- Clear visual hierarchy and composition.
- Consistent materials, lighting, scale, and proportions.
- Sufficient environmental density for the target platform and camera.
- Visual QA before declaring the work complete.

## Prototype exception
Primitive/blockout assets are acceptable only when the task is explicitly a blockout/prototype stage. The output must be labeled as such and must not be presented as final art.

## Model responsibility
- Opus: art direction, visual arbitration, difficult visual decisions.
- Sonnet: Blender creation, technical art, engine implementation, UI/asset execution.
- Haiku: lightweight visual checks when available.

Model routing is a policy; the runtime may limit actual model/sub-agent execution.
