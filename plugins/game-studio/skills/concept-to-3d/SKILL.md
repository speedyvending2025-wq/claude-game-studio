# Concept to 3D

Use when the user provides concept art, screenshots, mood boards, or a desired visual target.

Extract:
- camera/composition
- scene scale and perspective
- hero objects
- modular environment pieces
- prop count/density
- material families
- lighting direction and softness
- palette and contrast
- UI elements if visible
- character/vehicle silhouettes

Create an asset matrix with: asset, priority, reuse potential, Blender needed?, engine integration, and acceptance criteria.

Do not start with generic primitives unless the user explicitly asks for a blockout. The default goal is authored, reusable production assets.
