# Visual QA

Compare the current implementation against the approved reference and Visual Bible.

Score each category 0-5:
- composition/camera
- environment richness
- asset fidelity
- materials
- lighting/atmosphere
- color/style
- UI/presentation
- consistency

A score is evidence, not a substitute for judgment. Mark FAIL when a major category is materially below the target. Give the three highest-impact fixes first.

Never claim a visual comparison was performed unless the current result was actually inspected (screenshot, render, capture, or other available evidence).
