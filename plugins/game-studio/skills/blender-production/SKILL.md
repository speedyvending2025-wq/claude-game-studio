# Blender Production

Use Blender when authored 3D content will materially improve the target.

Prioritize:
- reusable modular kits
- clean topology appropriate to the target
- believable silhouettes
- material variation
- correct scale and pivots
- UV/material organization
- collision/LOD strategy where needed
- predictable engine export

For environments, build a kit rather than one-off geometry whenever reuse is possible. For hero assets, spend detail where the camera actually sees it.
