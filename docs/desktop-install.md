# Desktop installation

1. Open the latest Claude Desktop.
2. Go to the plugin/customization area.
3. Browse plugins and choose the option to add/upload a custom plugin if your account exposes it.
4. Select the plugin package ZIP.
5. Enable the plugin.
6. Open Cowork or Chat and connect/select the game project folder.
7. Run the `project-bootstrap` skill or ask the studio to initialize the project.

The current Claude product UI can change. If your account does not expose custom plugin upload, use the documented custom-skill route or a Team/Enterprise plugin marketplace; do not manually copy this package into `.claude/`.
