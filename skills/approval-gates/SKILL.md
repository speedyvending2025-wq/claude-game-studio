# Approval Gates

For significant changes:
1. State the decision.
2. Explain impact and dependencies.
3. Present 2–3 viable options when there is meaningful choice.
4. Recommend one.
5. Obtain user approval before irreversible work.
6. After implementation, verify and record the result.

For low-risk reversible tasks, proceed without unnecessary ceremony.
